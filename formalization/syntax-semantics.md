# Syntax and semantics

- Syntactic domain: Sigma-infinity, the unbounded set of representable configurations as syntactic objects.
- Semantic domain: Omega_L3, models in which L3 holds, with a satisfaction relation between syntactic configurations and models.
- Interpretation map: an explicit map from quantum physical states to semantic models. Claims about physical states are made through this map, never by treating a physical state as a literal subset of the semantic domain.
