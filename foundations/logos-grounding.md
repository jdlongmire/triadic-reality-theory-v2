# Logos grounding

**Claim status: interpretation. Separately identified metaphysical interpretation, not a formal premise.**

TRT holds that the logic-information-action triad is grounded in and dependent on the personal Logos. This is grounding and dependence, never identity: the triad is not the Logos.

Formal work in this repository must not use this interpretation as a premise in a proof. The bridge question, whether and how the unity of the triad is grounded, is tracked openly as TO-5, with theological premises formally separated from the formal development.
