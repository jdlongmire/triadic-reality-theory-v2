# Axioms (candidate)

**Claim status: axiom set for the candidate programme. Changes require JD's approval.**

- AX-1 (L3 as constraint): No actual state violates Identity, Non-Contradiction, or Excluded Middle.
- AX-2 (Representability): The representable domain I-infinity is unbounded; representability entails neither admissibility nor actuality.
- AX-3 (Action): There is a primitive transition relation A, not defined in terms of time, motion, force, or energy.
- AX-4 (Irreducibility): No co-primitive is definable from the other two. Status: programme axiom, argued in v1; a formal irreducibility proof is not claimed.
- AX-5 (Typed stages): Representable, admissible, actualizable, and actual are distinct types/stages; maps between them are explicit operators, never silent coercions.

Explicitly NOT axioms of v2: that L3-coherence suffices for actualizability; that decoherence selects outcomes; that partial trace erases all local coherence. Each was corrected in the v2 scientific baseline.
