# Agent entry point

## Cross-repository execution bootstrap

For governed GitHub execution, retrieve the current EBCC-001 v1.0 from jdlongmire/ai-bridge (`bootstrap/EBCC-001.md`) on current main and verify its version, status, and current-session tool capabilities. EBCC-001 is a shared operational discovery contract. It does not replace this repository's governing instructions, JD's authorization, or platform permissions. If inaccessible, report the gap and follow local governance; do not infer authority.

Read this repository's README, `governance/review-policy.md`, and `governance/claim-status-registry.md` before substantive work.

## Repository rules

- Work in a branch and pull request for material edits. No direct-to-main research changes without JD's explicit authorization and a recorded reason.
- Never change a claim status silently. Status changes go through the registry with evidence.
- Never present a Lean artifact as a verified theorem without the dependency and axiom audit in `validation/vv-plan.md`.
- Attribute all work product Human-Curated, AI-Enabled (HCAE) only.
- Ai-bridge is a coordination mailbox, not a source of domain authority and not a domain artifact store.
